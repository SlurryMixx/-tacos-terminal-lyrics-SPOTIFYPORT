What Is This?

Terminal lyrics visualizer with word-level synchronization.

Displays song lyrics in large ASCII block letters directly in your terminal while syncing them to whatever is currently playing in Spotify or another MPRIS-compatible media player.

This project is heavily inspired by and based on concepts from the original tacos-terminal-lyrics project, adapted specifically for Spotify-focused usage and terminal lyric visualization.

**Required**

Python >= 3.12

pyyaml

ffmpeg (provides ffprobe)

playerctl

**Installation**
Loki just install the file and drag it into your home folder and run "python3 lrcpop.py"
